PROJECT SUMMARY
Models that achieve 0.95+ cross-validation scores often cheat by relying on brittle single-feature shortcuts, redundant proxy variables, or in-distribution artifacts—collapsing silently under covariate shift.
`shortcut-hunter-mcp` is an automated ML Diagnostic & Stress-Testing Suite exposed as a CLI and MCP server. Given a tabular dataset, target, and selectable model family (`lightgbm`, `logistic_or_ridge`, or `pytorch_mlp`), it executes three automated robustness audits:
1. Iterative Top-Feature Knockout ("Signal Depth Audit"): Repeatedly identifies the #1 most predictive feature, removes it from the dataset, retrains, and plots the performance decay curve—distinguishing dangerously brittle 1-feature shortcut learning from deep, distributed signal, while tracking which secondary proxy features jump up to replace knocked-out features.
2. Synthetic Decoy / Confounder Stress Test: Injects calibrated noisy target-proxy ("Clever Hans" shortcut) features that hold on 90% of training rows but invert on an out-of-distribution stress split, measuring how vulnerable the model/regularization setup is to shortcut capture.
3. Covariate-Shift Slice Audit: Partitions feature space into distinct geometric clusters (PCA + K-Means) and evaluates Leave-One-Cluster-Out (LOCO) OOD generalization vs. standard random i.i.d. K-Fold CV to quantify the `iid_to_ood_drop` and pinpoint fragile subpopulations.

Outputs Dual Artifacts: a structured `<2,000`-token `manifest.json` ("Fragility Scorecard") for LLM agents + an interactive single-file Plotly `report.html` + raw `.parquet` audit tables for humans.

CORE FUNCTIONAL REQUIREMENTS

1. Iterative Knockout & Proxy Substitution (`knockout.py`):
   - Runs `k_steps` (default `min(8, n_features - 1)`). At step 0, evaluates full feature set via CV and computes permutation/gain feature importances.
   - At each step `i`, drops the #1 top feature from step `i-1`, retrains via CV, records metric mean/std, and records which remaining feature jumped most in normalized importance (`newly_promoted_proxy` + pairwise correlation with the dropped feature).
   - Distinguishes two patterns automatically:
     * Steep single-step cliff (`> 0.15` metric drop after 1 feature removal) -> `SINGLE_FEATURE_SHORTCUT_DEPENDENCY`.
     * Flat metric across removals of highly correlated features -> `REDUNDANT_PROXY_CLUSTER`.

2. Decoy Susceptibility Test (`decoy_test.py`):
   - Clones dataset in-memory, injects a synthetic shortcut feature correlated with `y` (`flip_prob = 0.08` on train, `flip_prob = 0.85` on an OOD evaluation set), trains the configured model pipeline, and computes `decoy_reliance_ratio` (importance share captured by decoy + metric collapse between in-distribution test and decoy-inverted OOD test).

3. Covariate-Shift LOCO Audit (`ood_slices.py`):
   - Standardizes numeric features, projects via PCA, clusters into `n_clusters` (default 5) via K-Means, and compares standard random 5-fold CV against Leave-One-Cluster-Out evaluation.
   - Identifies the worst-degrading OOD cluster and characterizes its feature centroid shifts (`z-score` deviations explaining *how* that slice differs from the bulk population).

4. Dual-Artifact Reporting (`reporting/`):
   - `manifest.json`: Compact `FragilityScorecard` JSON (<2,000 tokens) summarizing overall `risk_level`, `iid_cv_score` vs. `loco_ood_score` (`ood_degradation`), knockout decay summary, detected shortcut/proxy pairs, decoy capture score, worst OOD cluster profile, and paths to `report.html` and `.parquet` logs.
   - `report.html`: Interactive single-file Plotly dashboard featuring:
     a) Executive Fragility Scorecard Banner & Automated Governance Warnings.
     b) Iterative Feature-Knockout Performance Decay Curve (hovering each point shows which feature was knocked out and which proxy replaced it).
     c) Random i.i.d. CV vs. Leave-One-Cluster-Out OOD Bar Comparison + PCA 2D Scatter colored by cluster error rate.
     d) In-Distribution vs. Inverted-Shortcut Decoy Stress Test Chart.

5. MCP Server (`mcp_server.py`):
   Expose via `FastMCP("shortcut-hunter")`:
   - Tool `run_shortcut_audit(data_path: str, target_column: str, model_family: str = "lightgbm", knockout_steps: int = 6, n_ood_clusters: int = 5, output_dir: str = "runs") -> dict`
   - Tool `inspect_ood_cluster(run_id: str, cluster_id: int, output_dir: str = "runs") -> dict`: Returns centroid shift z-scores and worst failed rows inside that OOD cluster so the LLM can explain what kind of subpopulation breaks the model.
   - Resource `shortcut-hunter://runs/{run_id}/scorecard`
